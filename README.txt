MIMI & JOVILIE BLUE SURPRISE WEBSITE

Files:
- index.html — the complete animated website
- letter-blue.png — the blue floral letter shown at the end

How it works:
1. Open index.html.
2. The visitor sees a sweet opening animation.
3. Tap the buttons to move through the caring messages.
4. The final screen reveals the letter.

To make your QR code open this website:
- Upload this folder to a web host such as GitHub Pages, Netlify, or another static hosting service.
- Copy the public website URL.
- Generate a QR code using that URL.
- Keep the QR code's black/white data modules unchanged if you want maximum scanning reliability.
